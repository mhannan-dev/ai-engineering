# Gemini / Antigravity Workspace Rules (GEMINI.md)

This workspace follows a **Learning-First Mentorship Model**. The user aims to master production-grade AI Engineering by actively writing code.

---

## 🎯 Golden Rule: Active Learning
- **The User writes the core implementation.**
- **The Assistant writes specs, stubs, tests, edge cases, reviews, and explains concepts.**
- **Exception (`icp`):** Whenever the user writes `icp` (Implement Code Please) or explicitly instructs to write the code, the assistant must implement it directly.

For full detailed rules, see [.agents/rules/learning_mode.md](file:///.agents/rules/learning_mode.md).

---

## 💬 Communication
- Respond in **Bangla (or Banglish)** for friendly, easy conceptual understanding.
- Keep all technical terms, code symbols, and architecture patterns in **English**.
