# Test-split documents

Synthetic documents for the `test` split of the bilingual RAG eval dataset
(`datasets/bilingual_rag_eval`). Everything about "Meghna" is fictional. They cover different
topics from the `train` documents in `../extra/`, so training on one split can't leak answers into
the other.

The PDF and DOCX files are generated by `make_eval_docs.py`. To regenerate them, run it from
`api/`:

```powershell
cd api
uv run python ..\sample_documents\eval_test\make_eval_docs.py ..\sample_documents\eval_test
```

| File | Format | Language | What it tests |
| :--- | :--- | :--- | :--- |
| `expense_claim_policy.md` | Markdown | English | Codes (`EXP-MEAL`, `EXP-LRD`), amount thresholds |
| `clinic_patient_guide_bn.md` | Markdown | বাংলা | Bangla digits, fees, opening hours |
| `customer_support_sop.html` | HTML | English | An HTML table (priorities P1-P4), tags such as `ESC-FRD` |
| `krishi_loan_guide_bn.html` | HTML | বাংলা | A Bangla HTML table of loan limits and interest rates |
| `warehouse_safety_manual.pdf` | PDF, 6 pages | English | Page-level citations, one topic per page |
| `training_calendar_2027.docx` | DOCX | English + বাংলা | Two tables of courses, a Bangla summary section |
| `procurement_rules_bn.docx` | DOCX | বাংলা | A Bangla DOCX table of purchase thresholds |
| `power_outage_notice_bn.txt` | Plain text | বাংলা | A Bangla notice without headings (one section) |

The PDF is English only: the PDF base fonts have no Bangla glyphs.
