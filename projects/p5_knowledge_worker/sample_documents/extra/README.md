# Extra sample documents

Synthetic documents for trying uploads, search and chat by hand. Everything about "Northstar" is fictional. They are kept out of `eval_dataset.json`, so uploading them does not change the eval benchmark.

The PDF and DOCX files are generated by `make_sample_docs.py`. To regenerate them, run it from `api/` so it uses the API environment's `pymupdf` and `python-docx`:

```powershell
cd api
uv run python ..\sample_documents\extra\make_sample_docs.py ..\sample_documents\extra
```

| File | Format | Language | What it tests |
| :--- | :--- | :--- | :--- |
| `hr_leave_policy.md` | Markdown | English | Heading sections, exact codes (`LV-ANN`, `ENC-LV`) |
| `travel_allowance_policy_bn.md` | Markdown | বাংলা | Bangla tokenizer, Bangla digits, cross-lingual queries |
| `it_security_guidelines.html` | HTML | English | HTML headings and a table |
| `office_faq.txt` | Plain text | English | Text without headings (one section) |
| `ns200_sensor_manual.pdf` | PDF, 5 pages | English | Page-level citations (one topic per page) |
| `onboarding_guide.docx` | DOCX | English + বাংলা | DOCX headings, a table, a mixed-language section |
